# Luvtora 独立站运营系统实施与验收计划

## 目标与已知条件

一个 Mac 桌面入口覆盖独立站经营，云端持续执行工作。网站 https://luvtora.com，主营饰品，WooCommerce，约 42 SKU，目前暂无订单，Meta 曾投放，日预算 USD 45；后续 Google 广告与 TikTok 直播。

美国品类 Top 10 属于愿景，待定义细分类目、竞争范围、衡量方法与期限，不作为软件承诺。近期目标是可靠购买链路与追踪，获得可分析真实订单；随后验证贡献利润、履约稳定性与复购。

## 架构与实施选择

Mac Electron 控制台 + 业务服务 + 数据库与对象存储 + 工作流调度 + 平台连接器 + AI 模型。v0.1 使用本地原子写入 JSON 持久化，无云端服务。未来将业务数据迁移 PostgreSQL、素材迁移对象存储；本地保留受控缓存与凭证引用。

Activepieces 是已筛选的工作流底座候选（社区 MIT）；当前代码未嵌入其运行时，须完成许可、部署、连接器与可靠性验证后接入。Codex 通过官方 SDK / CLI 接入独立技术执行环境。文本模型与图像/视频模型分开选择，不能把文本脚本宣称为视频生成。

所有连接器约定：状态、权限、最近成功时间、失败原因、限流、重试、幂等键、数据版本与审计。用稳定平台 ID 映射 SKU、变体、广告、订单。初期单店单用户，后期再考虑多店和团队权限。

## 每条工作流的共同契约

输入来源与时间 → 事实/假设/缺失项 → 判断依据 → 方案 → 权限、预算、库存与利润检查 → 执行 → 验证 → 复查时间 → 回滚 → 归档。

执行级别：自动读取与草稿；授权范围内的低风险发布与常规回复；审批后的采购、退款、增预算与生产站修改。未经明确授权不发送消息、不投放、不退款。紧急暂停作用于所有写操作；恢复前核对积压任务，防止集中重复执行。

可靠性：接口限流、指数退避、最大重试、死信队列、幂等键、部分成功记录、凭证过期提示、监控与灾难恢复。不把失败或跳过的任务标为完成。定时任务需云端运行，Mac 合盖时继续执行的能力必须实际验证。

## 阶段交付

### P0：已建立 v0.1 基础

中文 Mac 应用代码、只读 Woo 适配器、CSV 指标、图片库、AI 文本方案、任务、手动复盘、审计、备份恢复。未以真实店铺凭证验证，未开放写操作。交付源码和 Apple Silicon / Intel 未签名试用包；Mac 真机、签名与公证单独验收。

### P1：真实数据和首单基础

Woo 商品变体与订单增量；成本/材质/尺寸/政策资料；Meta 只读数据；GA4 和 Pixel/CAPI、Search Console；购买/支付/退款验证；云端队列与每日复盘。先确认库存/物流/客服工具后选择连接器。

完成标准：后台数据对账、时间币种统一、测试购买事件去重、同步可重试、定时任务真实执行、敏感数据保护、备份恢复成功。

### P2：内容与获客

品牌模板；图像编辑和视频生成；SEO/Feed；Meta 宣发方案与实验；社媒排期和发布；外链合作候选。先从 3–5 个主推产品验证，避免一次生成全部 SKU 的高成本素材。

完成标准：媒体真实输出、商品一致性、授权检查、平台发布 ID、追踪完整、素材和实验版本可查、费用可控。初期写操作需审批，不能直接提高 $45 总日预算。

### P3：交易、履约和留存

客服知识库与工单；咨询核验、客诉升级；物流异常；库存预测、采购审批；促销与弃购/复购；财务贡献利润与现金流。

完成标准：订单到妥投与售后闭环，无重复资金操作，折扣受利润约束，客户退订/删除流程有效。

### P4：跨渠道与技术优化

Google、TikTok、达人联盟、直播辅助、多渠道归因、竞品研究；安全监测与 Codex 测试环境整改；在充分数据下扩大自动权限。

完成标准：逐平台真实验收，广告写操作受预算和异常暂停约束，修复可测试回滚；竞品不可得的数据标为估算。

## 店主需提供的业务资料（不是聊天中的密钥）

- 售价、商品成本、包装、美国配送、支付手续费、退款政策及大致退货成本。
- 供应商、发货地、交期、库存/仓储/物流工具。
- 品牌视觉参考、授权原图/实拍、已核实材质和尺寸。
- 广告账户、分析、客服、邮件与物流工具的安全连接授权。
- Mac 芯片类型与系统版本，用于选择安装包和真机验证。

所有凭证通过程序或环境安全设置填写，不能写进源码、计划、日志或聊天。

## 发行与运营成本

云端主机、数据库/存储、模型/视频费用、邮件/物流接口与 Apple Developer 发行费用单独预算；广告费独立计算。正式发行前签名、公证、自动更新的签名验证与回滚。v0.1 没有收取或实际支付这些费用。

排期在接口权限、供应链工具与真实账户验证后估算，不承诺未经评估的全部功能完成日期。

## 多语言与跨境客服补充

v0.1.2：主要导航/常用控件中英文切换；AI 客服支持 16 种语言和跟随原文模式，输出客服正文与核查备注，不发送。其他国家和方言按模型质量与人工核验逐步扩展，不能保证所有语言准确。

后续：统一社媒/邮件/网站收件箱、来源消息 ID、渠道账户授权、消息去重、订单身份核验、时区/SLA、原文与译文并存、品牌术语与禁用承诺、人工接管、平台回复窗口与营销同意。每个平台的收件和发送权限单独验证。自动回复仅在已授权渠道和明确业务规则内开放。国际化同时处理币种、单位、尺寸、日期、运费/关税与当地政策，不能只翻译字面内容。
